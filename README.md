# Менеджер рецептов
 
Консольное приложение для управления рецептами. Позволяет создавать блюда, добавлять ингредиенты, масштабировать количество порций и составлять общий список покупок.
 
## Установка
 
git clone <ссылка-на-репозиторий>
cd <папка>
pip install -r requirements.txt
 
## Использование
 
Классы импортируются из модулей проекта. Пример:
 
from Recipe import Recipe\
from Ingredient import Ingredient
 
pizza = Recipe("Пицца", [Ingredient("Мука", 500.0, "г")])\
print(pizza.scale(2))
 
Запуск тестов:
pytest
